# 🍔 Swiggy Clone – React.js

A fully responsive **Swiggy-inspired food ordering web application** built with **React.js**. This project fetches **live restaurant data from the Swiggy API**, dynamically renders restaurants and menus, and provides a smooth, modern user experience with routing, state management, and optimized performance.

---

## 🚀 Features

* 🍽️ Fetches **live restaurant data** from the Swiggy API.
* 📍 Dynamic restaurant listing based on location.
* 📋 Real-time restaurant menu data extraction.
* 🛒 Add, remove, and manage cart items using **Redux Toolkit**.
* 🚀 Client-side routing with **React Router DOM**.
* ⚡ Lazy Loading & Code Splitting for better performance.
* ✨ Shimmer UI while data is loading.
* 📱 Fully responsive design for desktop, tablet, and mobile devices.
* 🔄 Automatic UI updates based on live API responses.
* 🌐 Seamless navigation and redirection between pages.
* 🔗 **Redirects users to the official Swiggy website** for restaurant ordering.
* 🧩 Built with reusable and modular React components.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/karanbisht40/swiggy-clone.git
```

Move into the project folder:

```bash
cd swiggy-clone
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx parcel src/index.html
```
